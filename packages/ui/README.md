# @kition/tessera-ui

The components of [Kition Tessera](https://tessera.kition.ai), the design system for
professional editors: base controls, forms, data display, ribbon, dock and floating panels,
color picker and wheel, curves, histogram, timecode, transport, keyframes, level meter, and
workspace layout. Every component draws only through theme tokens, so one theme reskins them all.

```tsx
import '@kition/tessera-ui/styles.css'
import { Button, ColorPicker } from '@kition/tessera-ui'

<Button variant="primary">Save</Button>
```

Needs React 19. Every component, with live examples and props:
[tessera.kition.ai/docs](https://tessera.kition.ai/docs/overview/); the same pages as Markdown:
[docs/](https://github.com/KitionAI/kition-tessera/tree/main/docs).

Apache-2.0.
